# Take-Home Test - Data Science

Notebook ini merupakan analisis prediksi waktu pengiriman makanan secara akurat, 
Outline: preprocessing, serta pembuatan model prediksi yang relevan dengan studi kasus yang diberikan.

## 🛠️ Tools
- Python
- Pandas, Numpy
- Scikit-learn
- Matplotlib, Seaborn

## 📁 Struktur
- `notebooks/`: Notebook utama
- `README.md`: Penjelasan proyek
- `requirements.txt`: Library yang digunakan
- `.gitignore`: File yang diabaikan oleh Git

## 🚀 Cara Menjalankan
1. Buka `notebooks/take_home_test.ipynb`
2. Jalankan secara berurutan untuk melihat proses analisis dan modeling
